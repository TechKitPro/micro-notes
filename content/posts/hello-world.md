欢迎来到 **Micro Notes**！这是一个基于 [Hugo](https://gohugo.io/) 构建的技术笔记博客。

## 关于本站

本站用于记录编程、开发与学习过程中的点滴心得。希望这些笔记能对你有所帮助。

## 快速开始

### 新建文章

```bash
hugo new content posts/文章标题.md
```

### 生成静态文件

```bash
hugo
```

### 本地预览

```bash
hugo server
```

### 部署

推送到 Git 仓库后，Cloudflare Pages 会自动构建部署。
