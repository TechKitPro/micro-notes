欢迎来到 **Micro Notes**！这是一个基于 [Hexo](https://hexo.io/) 构建的技术笔记博客。

## 关于本站

本站用于记录编程、开发与学习过程中的点滴心得。希望这些笔记能对你有所帮助。

## 快速开始

### 新建文章

```bash
hexo new "文章标题"
```

### 生成静态文件

```bash
hexo generate
```

### 本地预览

```bash
hexo server
```

### 部署到 GitHub Pages

```bash
hexo deploy
```
